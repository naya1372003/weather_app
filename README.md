# ⛅ Weather App | تطبيق الطقس

A professional web application to check the current weather and 5-day forecast for any city.
تطبيق ويب احترافي للبحث عن حالة الطقس الحالية وتوقعات 5 أيام لأي مدينة.

## 🚀 Features | المميزات
- Search for any city | البحث عن أي مدينة.
- Geolocation support (Use My Location) | تحديد الموقع الحالي تلقائياً.
- 5-Day Forecast | توقعات الجو لـ 5 أيام.
- Dynamic Backgrounds & Emojis | خلفيات وإيموجي تتغير حسب حالة الجو.
- Error Handling | التعامل مع الأخطاء (مدينة غير موجودة).
- Clear button | زر لمسح البحث.

## 🛠️ Technologies | التقنيات المستخدمة
- HTML5
- CSS3 (Flexbox, Glassmorphism)
- JavaScript (Fetch API, Promises, DOM, Geolocation API)
- OpenWeatherMap API

## 🧠 What I Learned | ماذا تعلمت
- How to fetch data from an API | كيفية جلب البيانات من API.
- Handling asynchronous operations | التعامل مع العمليات غير المتزامنة.
- Parsing JSON data | تحليل بيانات JSON.
- Working with Date objects | التعامل مع التواريخ.

## 💻 How to Run | كيفية التشغيل
Open `index.html` in any browser. (Make sure to add your own API key in `script.js`).
